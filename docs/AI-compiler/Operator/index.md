# Operator(算子)

**算子开发**是指在AI新硬件适配场景中，针对特定硬件架构编写、优化对应**深度学习基础计算单元**实现代码的工作。在这篇原文语境里，它特指为新硬件开发卷积、GEMM、Batch Normalization等各类算子的核心任务，是新硬件AI软件栈开发中工作量占比最高的环节之一。

算子开发的核心定义是：针对GPU、NPU等AI加速硬件的架构特性，开发深度学习模型中最小计算单元的高效实现代码，通过优化内存访问、线程调度等方式最大化利用硬件算力，保障AI计算的性能上限。

维度拆解与延伸：

- 技术痛点：不同AI DSA架构差异极大，缺乏统一硬件ISA抽象，导致新硬件算子开发需从零开始，复杂度极高。
- 行业价值：高效的算子开发能直接降低AI服务的算力成本、提升响应速度，是大模型落地的核心技术基础之一。
- 主流工具：当前主流的算子开发技术包括CUDA、Triton、TileLang等，其中TileLang针对国产硬件适配痛点提供了分层编程模式，降低了开发门槛。
- 行业现状：当前AI芯片厂商、大模型厂商均大量投入算子开发相关岗位，同时也在探索AI辅助算子开发的落地路径。
