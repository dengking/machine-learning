# Optimization in AI compiler

AI编译器是连接上层深度学习框架与底层硬件（GPU/[ASIC](https://en.wikipedia.org/wiki/Application-specific_integrated_circuit)）的核心工具链，通过多级中间表示（IR）完成计算图化简、算子重构、内存优化、硬件指令映射，核心目标是破解访存瓶颈、提升算力利用率，尤其适配Transformer、MoE等大模型场景的算力需求。

## 一、通用核心优化技术（编译器标准层级）

### 1. 图级优化（中端高层，IR层面）

面向完整计算图做全局化简，是最基础、收益最高的优化手段。

- **算子融合（核心优化）**：将多个连续算子合并为单个内核，消除中间张量的全局显存写入，把数据留在片上缓存/寄存器中，是解决访存瓶颈的核心手段。分为三类：
  - 逐元素融合：Add + ReLU + Scale 等算子合并，风险最低、收益稳定；
  - 归约融合：将 Softmax 内部的 exp/sum/div 操作合并，避免多次遍历数据；
  - 计算密集型融合：如 Conv-BN-ReLU、Attention 全流程融合，需重新设计分块策略，收益最高。
- **经典图化简**：常量折叠、死代码消除、公共子表达式消除、冗余转置合并，直接移除无效计算与冗余节点。
- **布局变换**：如 NCHW → NHWC / NCHW4c，调整张量内存排布适配硬件缓存行，提升缓存命中率。
- **算子等价替换**：根据输入形状、硬件特性，自动选择更优实现（如 3×3 卷积切换 Winograd 算法）。

### 2. 算子级优化（中端底层，循环层面）

针对单个算子内核做细粒度调度优化，最大化单SM硬件利用率。

- **循环分块（Tiling）**：将大张量切分为适配共享内存容量的小块，最大化数据复用，减少全局访存。
- **循环重排、向量化、并行化**：适配 GPU SIMT 架构，匹配 Warp 级并行与 Tensor Core 指令要求。
- **自动调优**：通过 AutoTVM、Ansor、MetaSchedule 等搜索算法，在庞大的调度空间中自动搜索最优分块、向量化参数，针对特定硬件+输入形状生成定制化最优内核。

### 3. 内存优化（贯穿全编译栈）

- **内存复用与池化**：基于张量生命周期，让不同阶段的张量复用同一块显存，显著降低峰值显存占用。
- **静态内存规划**：编译期预分配所有张量内存，避免运行时频繁申请释放，消除调度开销。
- **访存对齐与合并**：调整内存地址与访问顺序，适配硬件突发传输特性，打满显存带宽。

### 4. 后端代码生成优化

- **硬件原语映射**：直接映射 Tensor Core、WMMA 等专用硬件指令，将矩阵乘等计算直接卸载到专用加速单元。
- **指令调度与流水线**：重排计算与访存指令，隐藏显存访问延迟，提升硬件流水线饱和度。
- **多SM负载均衡**：将计算任务均匀分发至 GPU 全部 SM，避免核心闲置，匹配你之前提到的 SM 并行架构。

## 二、大模型时代专项优化技术

针对 Transformer、MoE、长上下文、Agent AI 等场景的定制化编译优化，也是当前 Rubin/Blackwell 架构适配的核心方向。

### 1. 注意力机制专项优化

- **FlashAttention 系列融合编译**：自动将 QK 相乘、Softmax、V 相乘全流程融合，通过分块计算让中间数据全程驻留共享内存，大幅降低 HBM 访存，是当前大模型推理的核心性能来源。
- **PagedAttention 内存管理**：类虚拟内存的 KV 缓存调度机制，支持非连续显存块存储 KV，大幅提升显存碎片利用率，支持高并发批量推理与动态序列长度。
- **前缀缓存（Prompt Caching）**：自动识别重复的系统提示、RAG 上下文，缓存对应 KV 结果，增量计算新 Token；在 Agent AI 场景命中率极高，可将长上下文推理成本降低一个数量级。

### 2. MoE 模型专属编译优化

- **路由与通信流水化**：静态分析专家路由模式，优化专家分发、计算、归并的执行时序，将 All-to-All 通信与计算重叠，隐藏跨卡互联延迟，适配高速互联架构。
- **稀疏计算生成**：自动跳过未激活专家的计算，生成稀疏高效内核，避免无效算力开销。
- **专家负载均衡编译**：结合路由分布调整专家调度策略，解决专家负载不均导致的算力浪费。

### 3. 长上下文推理优化

- **KV 缓存量化压缩**：编译期自动对 KV 缓存做低比特量化（INT4/INT2）、稀疏化处理，线性降低长序列显存占用，支撑百万级 Token 场景。
- **分块流水线并行**：将超长上下文切分为数据块，流水化完成计算与通信，平衡单卡算力与跨卡传输开销。
- **稀疏注意力编译**：自动识别滑动窗口、块稀疏等注意力模式，生成定制化高效内核，剔除无效计算。

### 4. 低精度与量化编译

- **自动混合精度**：自动识别算子精度敏感度，在不损失效果的前提下切换 BF16/FP8/INT8，充分释放 Tensor Core 算力。
- **量化计算融合**：将权重反量化与算子计算融合为单内核，消除量化带来的额外访存开销，让 INT4/INT8 推理兼顾显存与速度。
