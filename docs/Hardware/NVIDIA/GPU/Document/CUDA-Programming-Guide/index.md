# [CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-programming-guide/index.html)

Even for developers who primarily use libraries, frameworks, or DSLs, an understanding of the **CUDA programming model** and how GPUs execute code is valuable in knowing what is happening behind the layers of abstraction. This guide starts with a chapter on the [CUDA programming model](https://docs.nvidia.com/cuda/cuda-programming-guide/01-introduction/programming-model.html#programming-model) outside of any specific programming language which is applicable to anyone interested in understanding how CUDA works, even non-developers.
